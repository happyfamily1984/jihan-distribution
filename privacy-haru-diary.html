📔 하루일기 개인정보 처리방침

시행일: 2026년 11월 22일 (1.1.0 반영)

하루일기(이하 "앱")는 사용자의 기록을 사용자의 휴대폰 안에만 보관하는 것을 원칙으로 합니다. 앱 개발자는 별도의 서버를 운영하지 않으며, 사용자의 일기·아이디어·녹음을 수집하거나 볼 수 없습니다.

1. 휴대폰에만 저장되는 정보

  • 일기·아이디어 글, 작성 시각, 월별 분석 결과
  • 글로 바뀌기 전의 녹음 파일 (글로 바뀌면 바로 지워집니다)
  • 사용자가 입력한 Google Gemini API 키, 내 단어장, 앱 설정

이 정보는 앱 안의 저장 공간에만 있으며, 앱을 지우면 함께 지워집니다. 휴대폰의 Google 자동 백업이 켜져 있으면 안드로이드 시스템이 기록과 설정을 사용자 본인의 Google 계정 백업에 암호화하여 보관할 수 있습니다(녹음 파일 제외). 사용자가 직접 "백업 파일 만들기"를 하면 사용자가 고른 위치에 파일이 저장됩니다.

2. 말로 기록하기 (휴대폰 음성 인식)

AI를 연결하지 않았을 때 말로 기록하면, 휴대폰에 들어 있는 기본 음성 인식 서비스(예: Google 음성 인식)가 말을 글로 바꿉니다. 이때 음성은 그 서비스의 정책에 따라 처리되며(기기에 따라 서버로 전송될 수 있음), 앱은 녹음 파일을 따로 저장하지 않습니다.

3. 외부로 보내지는 정보 (사용자가 AI 기능을 켠 경우에만)

사용자가 자신의 Gemini API 키를 연결하고 아래 기능을 쓸 때에만, 해당 내용이 Google LLC의 Gemini API로 전송됩니다.

  • 말로 기록하기(받아쓰기): 그 녹음 파일과 내 단어장
  • 이 달의 분석: 그 달의 일기·아이디어 글과 내 단어장
  • 키 확인: API 키 (올바른 키인지 확인할 때)

전송된 내용은 Google의 약관과 개인정보처리방침(Gemini API 추가 약관, Google 개인정보처리방침)에 따라 처리됩니다. 무료 등급으로 사용할 경우 Google이 서비스 개선을 위해 내용을 사용할 수 있으니, 민감한 내용은 AI 기능 없이 글로 기록하시기를 권합니다. AI 기능을 쓰지 않으면 어떤 기록도 휴대폰 밖으로 나가지 않습니다.

4. 앱이 쓰는 권한

  • 마이크: 사용자가 녹음 버튼을 눌렀을 때만 녹음합니다.
  • 다른 앱 위에 표시: 사용자가 켠 경우 📖 · 💡 플로팅 녹음 버튼을 보여 줍니다.
  • 포그라운드 서비스(마이크)·알림: 플로팅 버튼과 녹음이 다른 앱을 쓰는 동안에도 동작하도록 상시 알림을 표시하고, 매일 기록 알림을 보냅니다.
  • 인터넷: AI 기능(Gemini API)과 휴대폰 음성 인식에 씁니다.

5. 광고·분석 도구

앱에는 광고, 사용 통계·추적 도구가 없습니다.

6. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않습니다. Gemini API는 만 18세 이상 Google 계정에서 사용할 수 있습니다.

7. 정보의 삭제

각 기록은 앱에서 바로 삭제할 수 있고, 앱을 지우면 모든 정보가 삭제됩니다. API 키는 설정 → AI 연결 → 연결 해제로 지울 수 있습니다.
